Vue Solana は、Solana アプリケーションを構築するための Vue および Nuxt ライブラリを公開しているオープンソースプロジェクトです。公式の Solana JavaScript SDK（Solana Kit）を型付きのリアクティブなコンポーザブルでラップしているため、Vue 3 や Nuxt の開発者は RPC の配線を自前で書くことなく、残高の読み取り、ウォレットの検出、メッセージの署名、トランザクションの送信を行えます。

プロジェクトは Vue Solana チームがメンテナンスしており、GitHub 上でコミュニティからのコントリビューションを受け付けています。すべてのソースコードは MIT ライセンスで `https://github.com/vue-solana/vue-solana` にあり、各パッケージは `@vue-solana` スコープで npm に公開されています。

## パッケージが提供する機能

- `@vue-solana/core`: フレームワークに依存しない Solana の設定、エンドポイントヘルパー、ウォレットの型、トランザクションヘルパーです。
- `@vue-solana/vue`: RPC 読み取り、ウォレット、残高、メッセージ、署名、トランザクションのための Vue プラグインとコンポーザブルです。
- `@vue-solana/nuxt`: Vue プラグインをインストールし、コンポーザブルを自動 import する Nuxt モジュールです。

## プロジェクトの運営方法

開発は GitHub 上で公開して行われています。Issue でバグや機能リクエストを管理し、Pull Request はレビューを経て、リリースは npm に公開されます。いまお読みいただいているドキュメントは、このリポジトリ内の Markdown からビルドされ、Vercel でデプロイされています。

## ロードマップとガバナンス

予定されている機能は [ロードマップ](/ja/roadmap) ページで公開管理しています。パッケージの破壊的変更はセマンティックバージョニングに従い、このサイトの機械可読なサーフェス（llms.txt、openapi.json）は明示的なバージョニングポリシーとともに [OpenAPI 仕様](/ja/openapi.json) で文書化されています。
