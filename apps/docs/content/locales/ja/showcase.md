Vue Solana はデモだけでなく、実際のアプリのために作られています。このページでは、Vue Solana のパッケージで構築されたアプリを集めており、コンポーザブルが本番環境でどのように動くかを確認できます。

## Vue Solana で構築されたアプリ

::ShowcaseApp{name="Payvand" url="https://payvand-app.vercel.app/" logo="/payvand-logo.png" tag="Solana Pay"}
Payvand は、どんなスマートフォンでも Solana の販売端末に変えます。販売者は QR 決済リクエストを作成し、顧客はそれをスキャンしてウォレットから直接支払います。カードリーダーも、顧客側のアカウント作成も不要です。Nuxt 上に Vue Solana のパッケージを使って構築されており、Solana Pay のコンポーザブルで転送リクエストの作成、表示、スキャン、検証を行っています。
::
