有償のサポート窓口や電話回線はありません。Vue Solana はオープンソースプロジェクトであり、以下のすべてのチャネルは公開されているか、無料で利用できます。目的に合ったチャネルをお選びください。

## バグ報告と機能リクエスト

`https://github.com/vue-solana/vue-solana/issues` で GitHub Issue を作成してください。パッケージ名とバージョン（`@vue-solana/core`、`@vue-solana/vue`、`@vue-solana/nuxt` のいずれか）、お使いの Vue または Nuxt のバージョン、最小限の再現手順、エラーメッセージの全文を含めてください。Issue はメンテナがトリアージし、通常は数日以内に対応します。

## 使い方に関する質問

「X はどうやるのか」といった質問については、まず [トラブルシューティング](/ja/troubleshooting) ページをお読みください。よくあるセットアップやウォレットの問題を扱っています。そこで解決しない場合は、上記の情報を添えて GitHub Discussion または Issue を作成してください。

## セキュリティ報告

セキュリティ脆弱性について公開 Issue を作成しないでください。GitHub のセキュリティアドバイザリ機能 `https://github.com/vue-solana/vue-solana/security/advisories/new` から非公開で報告するか、リポジトリのプロフィール経由でメンテナに連絡してください。報告は 72 時間以内に確認し、修正と公開のタイムラインについてご相談します。

## プレスとブランディング

インタビュー、ロゴの使用、エコシステムへの掲載については、「press」ラベルを付けて通常の GitHub Issue を作成するか、リポジトリ経由でメンテナに連絡してください。プロジェクト名は「Vue Solana」、正規のドメインは `https://vue-solana-docs.vercel.app`、情報の一次ソースは `https://github.com/vue-solana` の GitHub オーガナイゼーションです。

## 回答に関する期待値

これはボランティアでメンテナンスされているオープンソースプロジェクトです。SLA はありませんが、メンテナは時間の許す範囲でトリアージ済みの Issue やセキュリティ報告に回答し、セキュリティ報告は優先的に扱います。
