Il n'existe pas de service de support payant ni de ligne téléphonique : Vue Solana est un projet open source, et chaque canal ci-dessous est public ou gratuit. Choisissez le canal qui correspond à votre besoin.

## Rapports de bugs et demandes de fonctionnalités

Ouvrez une issue GitHub à l'adresse `https://github.com/vue-solana/vue-solana/issues`. Précisez le package et la version (`@vue-solana/core`, `@vue-solana/vue` ou `@vue-solana/nuxt`), votre version de Vue ou de Nuxt, une reproduction minimale et le texte complet de l'erreur. Les issues sont triées par les mainteneurs, généralement en quelques jours.

## Questions d'utilisation

Pour les questions du type « comment faire pour… », consultez d'abord la page [Dépannage](/fr/troubleshooting) — elle couvre les problèmes de configuration et de wallet les plus courants. Si votre question n'y trouve pas de réponse, ouvrez une discussion ou une issue GitHub avec les détails ci-dessus.

## Rapports de sécurité

N'ouvrez pas d'issue publique pour les vulnérabilités de sécurité. Signalez-les en privé via la fonctionnalité d'avis de sécurité de GitHub à l'adresse `https://github.com/vue-solana/vue-solana/security/advisories/new`, ou contactez les mainteneurs via le profil du dépôt. Nous accuserons réception des rapports sous 72 heures et coordonnerons avec vous un calendrier de correction et de divulgation.

## Presse et image de marque

Pour les interviews, l'utilisation du logo ou les inscriptions dans l'écosystème, ouvrez une issue GitHub classique avec le label « press », ou joignez les mainteneurs via le dépôt. Le nom du projet est « Vue Solana » ; le domaine canonique est `https://vue-solana-docs.vercel.app` et la source de vérité est l'organisation GitHub à l'adresse `https://github.com/vue-solana`.

## Délais de réponse

Il s'agit d'un projet open source maintenu par des bénévoles. Il n'y a pas de SLA, mais les mainteneurs répondent aux issues triées et aux rapports de sécurité selon le temps disponible, et les rapports de sécurité sont traités en priorité.
