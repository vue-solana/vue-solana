Vue Solana est conçu pour de vraies applications, pas seulement des démos. Cette page rassemble des applications construites avec les packages Vue Solana, pour voir les composables fonctionner de bout en bout en production.

## Applications construites avec Vue Solana

::ShowcaseApp{name="Payvand" url="https://payvand-app.vercel.app/" logo="/payvand-logo.png" tag="Solana Pay"}
Payvand transforme n'importe quel téléphone en point de vente Solana. Les vendeurs créent une requête de paiement QR, les clients la scannent et paient directement depuis leur wallet — pas de terminal de paiement ni de création de compte pour le client. L'application est construite sur Nuxt avec les packages Vue Solana et utilise les composables Solana Pay pour créer, afficher, scanner et vérifier des requêtes de transfert.
::

## Faire figurer votre application

Vous avez construit une application avec `@vue-solana/core`, `@vue-solana/vue` ou `@vue-solana/nuxt` ? [Ouvrez une issue sur notre dépôt GitHub](https://github.com/vue-solana/vue-solana/issues/new?template=showcase-app.yml) avec le nom de l'application, un lien, une courte description et un logo carré, et elle sera ajoutée à cette page.
