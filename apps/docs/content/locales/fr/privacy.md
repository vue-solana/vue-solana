Ce site est un site de documentation. Il n'a ni comptes, ni connexion, ni base de données de visiteurs, et il ne demande ni ne traite directement de données personnelles.

## Ce qui est collecté

Le site utilise Vercel Analytics pour compter les pages vues. Vercel Analytics fonctionne sans cookies et n'utilise pas d'identifiants persistants susceptibles d'isoler un visiteur individuel : il enregistre des agrégats tels que le chemin de la page, le référent, le pays et la catégorie d'appareil, sans construire de profils utilisateurs.

L'infrastructure du serveur web (Vercel et son CDN) traite les métadonnées de requête standard telles que l'adresse IP, le user agent et l'URL demandée, à des fins techniques de diffusion du contenu, de sécurité et de prévention des abus, comme le décrit la documentation de confidentialité de Vercel. Les opérateurs du site n'exécutent aucun journal ni aucune analytics supplémentaire au-delà de Vercel Analytics.

## Ce qui n'est pas collecté

- Aucun cookie n'est déposé par ce site à des fins de suivi.
- Aucun formulaire : ce site n'a pas de formulaire de commentaires, d'inscription à une newsletter ni de champs de saisie, donc rien de ce que vous tapez n'y est stocké.
- Aucune publicité, aucun traqueur intersite et aucun script de fingerprinting.
- Aucune vente ni aucun partage de données de visiteurs avec des courtiers en données.

## Contenu tiers

Les pages de documentation intègrent des exemples de code mais ne chargent ni publicité tierce ni widget social. Les liens externes (GitHub, npm, la page de démo) sont régis par les politiques de confidentialité de ces destinations.

## Agents automatisés

Les agents et crawlers automatisés sont les bienvenus dans le respect des conventions de limite de débit documentées dans `/openapi.json`. Le trafic des agents est traité comme toute autre métadonnée de requête : il peut apparaître dans les analytics agrégées et n'est corrélé à aucun individu.

## Modifications

Si les pratiques de collecte de données changent, cette page sera mise à jour avant l'entrée en vigueur de ces changements. La page actuelle est la description faisant autorité de la posture de confidentialité du site.

Pour toute question de confidentialité, consultez la page [Contact](/fr/contact).
