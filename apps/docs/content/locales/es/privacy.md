Este sitio es una web de documentación. No tiene cuentas, ni inicio de sesión, ni base de datos de visitantes, y no solicita ni procesa datos personales directamente.

## Que Se Recoge

El sitio usa Vercel Analytics para contar vistas de página. Vercel Analytics no usa cookies ni identificadores persistentes que puedan singularizar a un visitante individual: registra agregados como la ruta de la página, el referrer, el pais y la clase de dispositivo, sin construir perfiles de usuario.

La infraestructura del servidor web (Vercel y su CDN) procesa metadatos de petición estandar como la dirección IP, el user agent y la URL solicitada con los fines tecnicos de servir contenido, seguridad y prevención de abusos, según describe la documentación de privacidad de Vercel. Los operadores del sitio no ejecutan registro ni analiticas adicionales más alla de Vercel Analytics.

## Que No Se Recoge

- Este sitio no establece cookies con fines de rastreo.
- Sin formularios: este sitio no tiene formularios de comentarios, suscripciones ni introducción de datos, así que nada de lo que escribas se almacena aquí.
- Sin publicidad, sin rastreadores entre sitios y sin scripts de fingerprinting.
- No se venden ni comparten datos de visitantes con intermediarios de datos.

## Contenido De Terceros

Las paginas de documentación incluyen ejemplos de código pero no cargan publicidad de terceros ni widgets sociales. Los enlaces externos (GitHub, npm, la página de demo) se rigen por las politicas de privacidad de esos destinos.

## Agentes Automaticos

Los agentes y crawlers automaticos son bienvenidos dentro de las convenciones de rate limit documentadas en `/es/openapi.json`. El trafico de agentes se trata igual que cualquier otro metadato de petición: puede aparecer en analiticas agregadas y no se correlaciona con ningun individuo.

## Cambios

Si las practicas de recopilación de datos cambian, esta página se actualizara antes de que esos cambios entren en vigor. Esta página es la descripción autoritativa de la postura de privacidad del sitio.

Para preguntas de privacidad, consulta la página de [Contacto](/es/contact).
