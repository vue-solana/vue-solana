No hay mesa de soporte de pago ni telefono: Vue Solana es un proyecto de codigo abierto, y todos los canales siguientes son publicos o gratuitos. Elige el canal que se ajuste a lo que necesitas.

## Reportes De Bugs Y Peticiones De Funcionalidades

Abre un issue de GitHub en `https://github.com/vue-solana/vue-solana/issues`. Incluye el paquete y la version (`@vue-solana/core`, `@vue-solana/vue` o `@vue-solana/nuxt`), tu version de Vue o Nuxt, una reproduccion minima y el texto completo del error. Los issues son triados por los mantenedores, normalmente en pocos dias.

## Preguntas De Uso

Para preguntas de "como hago X", lee primero la pagina de [Solucion de problemas](/es/troubleshooting) — cubre los problemas mas comunes de configuracion y wallets. Si tu pregunta no aparece ahi, abre una discusion o issue de GitHub con los detalles indicados arriba.

## Reportes De Seguridad

No abras issues publicos para vulnerabilidades de seguridad. Reportalas de forma privada mediante la funcion de avisos de seguridad de GitHub en `https://github.com/vue-solana/vue-solana/security/advisories/new`, o contacta a los mantenedores a traves del perfil del repositorio. Confirmaremos los reportes en un plazo de 72 horas y coordinaremos contigo la solucion y el calendario de divulgacion.

## Prensa Y Marca

Para entrevistas, uso del logo o listados en ecosistemas, abre un issue de GitHub normal con la etiqueta "press", o contacta a los mantenedores a traves del repositorio. El nombre del proyecto es "Vue Solana"; el dominio canonico es `https://vue-solana-docs.vercel.app` y la fuente de verdad es la organizacion de GitHub en `https://github.com/vue-solana`.

## Expectativas De Respuesta

Este es un proyecto de codigo abierto mantenido por voluntarios. No hay SLA, pero los mantenedores responden a los issues triados y a los reportes de seguridad segun lo permite el tiempo, y los reportes de seguridad se tratan con prioridad.
