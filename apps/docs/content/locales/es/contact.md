No hay mesa de soporte de pago ni telefono: Vue Solana es un proyecto de código abierto, y todos los canales siguientes son publicos o gratuitos. Elige el canal que se ajuste a lo que necesitas.

## Reportes De Bugs Y Peticiones De Funcionalidades

Abre un issue de GitHub en `https://github.com/vue-solana/vue-solana/issues`. Incluye el paquete y la versión (`@vue-solana/core`, `@vue-solana/vue` o `@vue-solana/nuxt`), tu versión de Vue o Nuxt, una reproducción minima y el texto completo del error. Los issues son triados por los mantenedores, normalmente en pocos dias.

## Preguntas De Uso

Para preguntas de "como hago X", lee primero la página de [Solución de problemas](/es/troubleshooting) — cubre los problemas más comunes de configuración y wallets. Si tu pregunta no aparece ahi, abre una discusión o issue de GitHub con los detalles indicados arriba.

## Reportes De Seguridad

No abras issues publicos para vulnerabilidades de seguridad. Reportalas de forma privada mediante la función de avisos de seguridad de GitHub en `https://github.com/vue-solana/vue-solana/security/advisories/new`, o contacta a los mantenedores a traves del perfil del repositorio. Confirmaremos los reportes en un plazo de 72 horas y coordinaremos contigo la solución y el calendario de divulgación.

## Prensa Y Marca

Para entrevistas, uso del logo o listados en ecosistemas, abre un issue de GitHub normal con la etiqueta "press", o contacta a los mantenedores a traves del repositorio. El nombre del proyecto es "Vue Solana"; el dominio canonico es `https://vue-solana-docs.vercel.app` y la fuente de verdad es la organización de GitHub en `https://github.com/vue-solana`.

## Expectativas De Respuesta

Este es un proyecto de código abierto mantenido por voluntarios. No hay SLA, pero los mantenedores responden a los issues triados y a los reportes de seguridad según lo permite el tiempo, y los reportes de seguridad se tratan con prioridad.
