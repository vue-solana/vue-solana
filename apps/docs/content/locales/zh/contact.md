本项目没有付费支持热线或电话：Vue Solana 是一个开源项目，以下所有渠道都是公开或免费的。请根据需求选择对应的渠道。

## 缺陷报告与功能请求

在 `https://github.com/vue-solana/vue-solana/issues` 提交 GitHub issue。请附上包名和版本（`@vue-solana/core`、`@vue-solana/vue` 或 `@vue-solana/nuxt`）、你的 Vue 或 Nuxt 版本、最小复现步骤以及完整的错误文本。维护者通常会在几天内对 issue 进行分诊。

## 使用问题

对于"如何做 X"类问题，请先阅读[故障排查](/zh/troubleshooting)页面——它涵盖了最常见的配置和钱包问题。如果那里没有答案，请附上上述信息并提交 GitHub 讨论或 issue。

## 安全报告

安全漏洞请勿提交公开 issue。请通过 GitHub 的安全公告功能 `https://github.com/vue-solana/vue-solana/security/advisories/new` 私下报告，或通过仓库主页联系维护者。我们会在 72 小时内确认报告，并与你协调修复和披露时间表。

## 媒体与品牌

如需访谈、Logo 使用或生态系统收录，请提交带有 "press" 标签的普通 GitHub issue，或通过仓库联系维护者。项目名称为 "Vue Solana"；规范域名为 `https://vue-solana-docs.vercel.app`，权威来源是 `https://github.com/vue-solana` 的 GitHub 组织。

## 响应预期

这是一个由志愿者维护的开源项目。没有 SLA，但维护者会尽力响应已分诊的 issue 和安全报告，安全报告会被优先处理。
