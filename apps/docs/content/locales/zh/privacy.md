本站是一个文档网站。它没有账号、没有登录、没有访客数据库，也不会直接索取或处理个人数据。

## 我们收集什么

本站使用 Vercel Analytics 统计页面浏览量。Vercel Analytics 不使用 cookie，也不使用能够识别单个访客的持久标识符：它只记录页面路径、来源、国家、设备类型等聚合信息，不会建立用户画像。

Web 服务器基础设施（Vercel 及其 CDN）会处理 IP 地址、用户代理、请求 URL 等标准请求元数据，用于提供内容、安全和防滥用等技术目的，详见 Vercel 自己的隐私文档。本站运营者不运行 Vercel Analytics 之外的额外日志或分析。

## 我们不收集什么

- 本站不设置用于跟踪的 cookie。
- 无表单：本站没有评论表单、订阅登记或数据输入字段，因此你输入的任何内容都不会在此存储。
- 无广告、无跨站跟踪器、无指纹识别脚本。
- 不向数据经纪商出售或共享访客数据。

## 第三方内容

文档页面内嵌代码示例，但不会加载第三方广告或社交小部件。外部链接（GitHub、npm、演示页）受这些目标站点自身隐私政策的约束。

## 机器代理

欢迎自动化代理和爬虫在 `/zh/openapi.json` 中记载的速率限制约定范围内访问。代理流量与其他请求元数据一视同仁：可能出现在聚合分析中，但不会与任何个人相关联。

## 变更

如果数据收集做法发生变化，本页面将在变更生效之前更新。当前页面是本站隐私态势的权威描述。

如有隐私问题，请参阅[联系](/zh/contact)页面。
