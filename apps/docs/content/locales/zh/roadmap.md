这些包已稳定可用于生产，包括 RPC 读取、钱包发现与连接、余额查询、交易、账户读取、消息签名和规范化错误处理。本路线图按影响力排序描述后续计划，不绑定到特定版本。

## 生态集成

- 基于 Kit 客户端的 SPL 代币账户辅助工具和代币余额 composables。
- 通过统一钱包流程中的协议链接支持桌面原生钱包。
- 更多 iOS 钱包提供商。

## 开发者体验

- Anchor provider 和程序辅助工具。
- 专用的钱包弹窗或 UI 包。
- 用于服务端读取的 Nuxt 服务端 RPC 工具。

## 弹性和高级模式

- RPC 提供方故障转移与速率限制处理。
- 高级程序账户索引模式与缓存。
- 交易模拟辅助工具。
- 用于实时链上数据的事件订阅抽象。
