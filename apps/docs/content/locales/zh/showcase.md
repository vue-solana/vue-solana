Vue Solana 不仅为示例而生，更为真实的应用而生。本页汇集了基于 Vue Solana 包构建的应用，让你看到这些 composable 在生产环境中端到端地运行。

## 使用 Vue Solana 构建的应用

::ShowcaseApp{name="Payvand" url="https://payvand-app.vercel.app/" logo="/payvand-logo.png" tag="Solana Pay"}
Payvand 可以把任何一部手机变成 Solana 销售终端。卖家创建一个二维码支付请求，顾客扫码后直接从钱包付款——无需刷卡机，顾客也无需注册账户。它基于 Nuxt 和 Vue Solana 包构建，使用 Solana Pay composable 来创建、展示、扫描并验证转账请求。
::

## 让你的应用出现在这里

用 `@vue-solana/core`、`@vue-solana/vue` 或 `@vue-solana/nuxt` 构建了应用？发送邮件到 [mohsenpk1370@gmail.com](mailto:mohsenpk1370@gmail.com)，附上应用名称、链接、简短说明和一张正方形 logo，我们会把它添加到这个页面。
