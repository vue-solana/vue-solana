이 사이트는 문서 웹사이트입니다. 계정도, 로그인도, 방문자 데이터베이스도 없으며, 개인 데이터를 직접 요청하거나 처리하지 않습니다.

## 수집하는 것

이 사이트는 페이지 조회수를 세기 위해 Vercel Analytics를 사용합니다. Vercel Analytics는 쿠키가 없고 개인 방문자를 식별할 수 있는 영속 식별자를 사용하지 않습니다: 페이지 경로, 리퍼러, 국가, 기기 클래스 같은 집계만 기록하며 사용자 프로필을 만들지 않습니다.

웹 서버 인프라(Vercel과 그 CDN)는 콘텐츠 제공, 보안, 어뷰즈 방지라는 기술적 목적을 위해 IP 주소, 사용자 에이전트, 요청된 URL 같은 표준 요청 메타데이터를 처리합니다. 이는 Vercel 자체의 개인정보 문서에 설명되어 있습니다. 사이트 운영자는 Vercel Analytics 외에 추가 로깅이나 애널리틱스를 운영하지 않습니다.

## 수집하지 않는 것

- 이 사이트는 추적 목적의 쿠키를 설정하지 않습니다.
- 폼 없음: 이 사이트에는 댓글 폼, 뉴스레터 구독, 데이터 입력 필드가 없으므로 입력한 어떤 것도 여기에 저장되지 않습니다.
- 광고, 교차 사이트 트래커, 핑거프린팅 스크립트가 없습니다.
- 방문자 데이터를 데이터 브로커에게 판매하거나 공유하지 않습니다.

## 제3자 콘텐츠

문서 페이지는 코드 예제를 포함하지만 제3자 광고나 소셜 위젯을 로드하지 않습니다. 외부 링크(GitHub, npm, 데모 페이지)는 해당 목적지의 개인정보 처리방침의 적용을 받습니다.

## 기계 에이전트

자동화된 에이전트와 크롤러는 `/ko/openapi.json`에 문서화된 rate limit 규약 범위 내에서 환영받습니다. 에이전트 트래픽은 다른 모든 요청 메타데이터와 동일하게 취급됩니다: 집계 애널리틱스에는 나타날 수 있지만 개인과 연관되지는 않습니다.

## 변경 사항

데이터 수집 관행이 변경되면 이 페이지는 해당 변경이 적용되기 전에 업데이트됩니다. 현재 페이지가 사이트 개인정보 태세에 대한 권위 있는 설명입니다.
