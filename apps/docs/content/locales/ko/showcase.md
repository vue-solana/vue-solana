Vue Solana는 데모가 아니라 실제 앱을 위해 만들어졌습니다. 이 페이지는 Vue Solana 패키지로 구축된 앱을 모아, 컴포저블이 프로덕션에서 어떻게 작동하는지 보여줍니다.

## Vue Solana로 구축된 앱

::ShowcaseApp{name="Payvand" url="https://payvand-app.vercel.app/" logo="/payvand-logo.png" tag="Solana Pay"}
Payvand는 어떤 휴대폰이든 Solana 판매 단말기로 바꿔줍니다. 판매자는 QR 결제 요청을 만들고, 고객은 이를 스캔해 지갑에서 바로 결제합니다. 카드 리더기도, 고객의 계정 생성도 필요 없습니다. Nuxt 위에 Vue Solana 패키지로 구축되었으며, Solana Pay 컴포저블을 사용해 송금 요청을 생성, 표시, 스캔, 검증합니다.
::
