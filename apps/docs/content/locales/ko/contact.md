유료 지원 센터나 전화 번호는 없습니다: Vue Solana는 오픈 소스 프로젝트이며 아래의 모든 채널은 공개되어 있거나 무료입니다. 필요한 것에 맞는 채널을 선택하세요.

## 버그 보고 및 기능 요청

`https://github.com/vue-solana/vue-solana/issues`에서 GitHub 이슈를 열어주세요. 패키지와 버전(`@vue-solana/core`, `@vue-solana/vue` 또는 `@vue-solana/nuxt`), Vue 또는 Nuxt 버전, 최소 재현 코드, 전체 오류 메시지를 포함해 주세요. 이슈는 보통 며칠 안에 메인테이너가 분류합니다.

## 사용 질문

"X를 어떻게 하나요" 류의 질문은 먼저 [문제 해결](/ko/troubleshooting) 페이지를 읽어보세요 — 가장 흔한 설정 및 지갑 문제를 다룹니다. 거기에 답이 없다면 위의 내용과 함께 GitHub 토론이나 이슈를 열어주세요.

## 보안 보고

보안 취약점은 공개 이슈로 열지 마세요. `https://github.com/vue-solana/vue-solana/security/advisories/new`의 GitHub 보안 자문 기능을 통해 비공개로 보고하거나, 저장소 프로필을 통해 메인테이너에게 연락해 주세요. 72시간 이내에 보고를 확인하고 수정 및 공개 일정을 조율하겠습니다.

## 언론 및 브랜딩

인터뷰, 로고 사용, 생태계 등재 문의는 "press" 라벨과 함께 일반 GitHub 이슈를 열거나 저장소를 통해 메인테이너에게 연락해 주세요. 프로젝트 이름은 "Vue Solana"이며, 공식 도메인은 `https://vue-solana-docs.vercel.app`이고, 신뢰할 수 있는 출처는 `https://github.com/vue-solana`의 GitHub 조직입니다.

## 응답 기대치

이 프로젝트는 자원봉사자가 유지보수하는 오픈 소스입니다. SLA는 없지만, 메인테이너는 시간이 허락하는 대로 분류된 이슈와 보안 보고에 응답하며, 보안 보고는 우선순위로 처리합니다.
