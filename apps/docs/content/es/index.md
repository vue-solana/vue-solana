Vue Solana es un conjunto de paquetes para crear aplicaciones Solana con Vue y Nuxt. El objetivo es ofrecer primitivas idiomáticas para Vue, manteniendo una base compatible con las APIs modernas de Solana.

## Paquetes

- `@vue-solana/core`: primitivas independientes del framework para configuración, RPC, wallets y transacciones.
- `@vue-solana/vue`: plugin de Vue y composables para usar RPC, balances, wallets, firmas y transacciones.
- `@vue-solana/nuxt`: módulo de Nuxt que instala el plugin de Vue y autoimporta composables.
