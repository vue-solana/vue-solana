There is no paid support desk or phone line: Vue Solana is an open-source project, and every channel below is public or free to use. Pick the channel that matches what you need.

## Bug Reports And Feature Requests

Open a GitHub issue at `https://github.com/vue-solana/vue-solana/issues`. Include the package and version (`@vue-solana/core`, `@vue-solana/vue`, or `@vue-solana/nuxt`), your Vue or Nuxt version, a minimal reproduction, and the full error text. Issues are triaged by the maintainers, usually within a few days.

## Usage Questions

For "how do I do X" questions, read the [Troubleshooting](/troubleshooting) page first — it covers the most common setup and wallet problems. If your question is not answered there, open a GitHub discussion or issue with the details above.

## Security Reports

Do not open public issues for security vulnerabilities. Report them privately through GitHub's security advisory feature at `https://github.com/vue-solana/vue-solana/security/advisories/new`, or contact the maintainers through the repository profile. We will acknowledge reports within 72 hours and coordinate a fix and disclosure timeline with you.

## Press And Branding

For interviews, logo usage, or ecosystem listings, open a regular GitHub issue with the "press" label, or reach the maintainers through the repository. The project name is "Vue Solana"; the canonical domain is `https://vue-solana-docs.vercel.app` and the source of truth is the GitHub organization at `https://github.com/vue-solana`.

## Response Expectations

This is a volunteer-maintained open-source project. There is no SLA, but maintainers respond to triaged issues and security reports as time allows, and security reports are treated with priority.
