Vue Solana is built for real apps, not just demos. This page collects apps that ship on the Vue Solana packages, so you can see the composables working end to end in production.

## Apps Built With Vue Solana

::ShowcaseApp{name="Payvand" url="https://payvand-app.vercel.app/" logo="/payvand-logo.png" tag="Solana Pay"}
Payvand turns any phone into a Solana point of sale. Sellers create a QR payment request, customers scan it and pay straight from their wallet — no card reader, no account setup for the customer. It is built on Nuxt with the Vue Solana packages, using the Solana Pay composables to build, render, scan, and verify transfer requests.
::

## Get Your App Listed

Built an app with `@vue-solana/core`, `@vue-solana/vue`, or `@vue-solana/nuxt`? [Open an issue on our GitHub repo](https://github.com/vue-solana/vue-solana/issues/new?template=showcase-app.yml) with the app name, a link, a short description, and a square logo, and it will be added to this page.
